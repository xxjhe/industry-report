## 第 1 步：HTML 报告硬性规范（每份必须全部满足）

### 1.1 页眉品牌（强制，最高优先级）
- **每份 HTML 报告的每页页眉必须显示「信息聚合知识星球」**。
- 实现：页面顶部固定页眉栏（`position: sticky/fixed`），左侧品牌文字「信息聚合知识星球」，右侧可放行业名 + run_id + 日期。
- **打印/分页兼容**：加 `@media print` 样式与 `@page` 边距配置，确保导出 PDF 或打印时每一页都带页眉（可用 `position: fixed` 页眉 + 正文 `margin-top` 留白实现）。
- 页眉样式统一：深色底（如 #1a2233）白字，或浅色底深色字，与正文主题协调即可，但品牌文字必须一字不差。

### 1.2 图表化（核心要求）
**结构性信息尽可能用图表输出，禁止大段数字罗列**。映射规则：

| 信息类型 | 首选图表 |
|----------|----------|
| 市场规模/出货量/渗透率 趋势与预测 | 折线图 / 柱状图（历史+预测分段配色） |
| 量价拆分、增速加速度 | 双轴折线+柱状组合图 |
| 产业链结构（上中下游环节与流向） | Sankey 桑基图 / 自定义节点链路图 |
| 成本拆分（成本构成占比） | 饼图/环形图 或 瀑布图 |
| 利润池分布（各环节毛利率/利润占比） | 横向条形图 / 桑基图 |
| 竞争格局（CR/份额） | 条形图（份额降序） |
| 技术路线对比（多维度打分） | 雷达图 + 对比表格 |
| 价格趋势 | 折线图（涉及股价涨跌时遵循 A 股惯例：**涨红跌绿**） |
| 供需平衡表/情景测算 | 高亮表格 + 柱状图 |

- 图表库：**ECharts 5**（默认 CDN 引入 `https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js`；若目标环境离线，下载 echarts.min.js 到 `10-HTML报告/assets/` 本地引用）。
- **数据保真红线**：图表中的每一个数字必须来自源 MD 报告或 `08-数据与图表附件/data_ledger.csv`，**禁止为画图而编造/凑数**；源报告中的 ✅/⚠️/🔴 可信度标记须在图表标题或图注中保留。
- 每份报告图表数量指引：数据密集型章节逐节配图；全文至少 5 张有意义的图表（终稿至少 8 张），但不许为凑数把一句话也做成图。

### 1.3 版式与交互
- 单文件 HTML（CSS/JS 内联，除 ECharts 库外无外部依赖），中文衬线/无衬线字体栈，正文最大宽度约 900px 居中。
- 左侧或顶部**章节目录导航**（锚点跳转），长报告加"返回顶部"。
- 表格带斑马纹与表头吸顶；关键结论用卡片/引用块突出；🔴🟡🟢 标记与原报告一致。
- 浅色主题为主（打印友好）；配色克制（主色不超过 3 种）。
- 文末保留原报告的《数据来源清单》《待核验清单》与免责声明，不得删减。

## 第 2 步：转换执行（逐份进行）
1. 通读源 MD 全文 → 提取章节结构、全部图表候选数据点（登记数据出处行号）；
2. 生成 HTML → **边写边存**（单文件超过一次写入上限时分段追加写）；
3. 每份写完后自检（见第 3 步）再转下一份。

## 第 3 步：自检清单（每份必过）
- [ ] 页眉「信息聚合知识星球」存在且文字一字不差（屏幕 + 打印样式均有）
- [ ] 全部图表数字与源 MD/data_ledger 一致，可信度标记保留
- [ ] 章节结构完整覆盖源报告（无章节丢失，无内容改写观点）
- [ ] HTML 可独立打开（浏览器直接打开无报错、图表正常渲染）
- [ ] 《数据来源清单》《待核验清单》完整保留

## 输出格式
- 产物目录：`10-HTML报告/`（不存在则创建）
- 完成后向 Leader 返回：转换文件清单（路径+大小+图表数）、跳过/失败项及原因、自检结果

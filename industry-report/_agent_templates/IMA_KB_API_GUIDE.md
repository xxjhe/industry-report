## 二、MCP 工具接口

### 2.1 全局知识搜索

在**指定知识库**中搜索关键词，返回匹配的知识条目列表。

```
工具：mcp__ima-mcp__search_knowledge
参数：
{
  "params": [
    {
      "kb_ids": ["<kbId1>", "<kbId2>", ...],   // 必填，知识库 ID 列表
      "query": "<搜索关键词>",                   // 必填
      "limit": 20                                // 可选，返回条数上限
    }
  ]
}
```

**调用示例**：在纪要库和研报库中搜索"固态电池"：

```json
{
  "params": [
    {
      "kb_ids": ["<YOUR_KB_ID_MINUTES>", "<YOUR_KB_ID_GENERAL>", "<YOUR_KB_ID_REPORT_B>"],
      "query": "固态电池",
      "limit": 20
    }
  ]
}
```

### 2.2 获取知识库内容列表

浏览某个知识库的知识条目列表（分页）。

```
工具：mcp__ima-mcp__get_knowledge_list
参数：
{
  "kb_id": "<kbId>",       // 必填
  "limit": 20,             // 可选
  "cursor": "<分页游标>"   // 可选，用于翻页
}
```

### 2.3 获取知识详情

获取某条知识的完整内容。

```
工具：mcp__ima-mcp__fetch_media_content
参数：
{
  "params": [
    {
      "kb_id": "<kbId>",
      "knowledge_id": "<knowledge_id>"   // 从 search_knowledge 返回结果中获取
    }
  ]
}
```

## 三、使用策略

### 3.1 推荐搜索范围

| 研究场景 | 推荐知识库组合 | 理由 |
|----------|---------------|------|
| **公司/行业深度研究** | 全部 7 个 | 全面覆盖纪要、研报、专家交流 |
| **卖方研报** | 自有研报库B + 自有综合库 + 外资研报 | 覆盖中资券商、国际投行 |
| **产业调研/专家观点** | 产业调研库A×2 + 自有产业调研库B | 侧重一手产业信息 |
| **个股纪要** | 自有纪要库 + 自有综合库 | 5万+纪要覆盖，历史最久 |
| **外资/全球宏观** | 外资研报 + 自有研报库B | 25年外资研报 + 国际投行 |
| **快速概览** | 自有综合库（最大） | 单库5万+条，覆盖面广 |

### 3.2 执行规则

1. **默认行为**：Agent 搜索知识库时，`kb_ids` 参数**必须且只能**使用上述 7 个知识库 ID，不得使用其他知识库。
2. **精度优先**：如果用户指定了具体行业/公司，优先选择相关性高的知识库组合（见上表），而非全量搜索。
3. **分页控制**：单次 `limit` 建议 10-20，避免返回过多低质量结果。
4. **去重**：多个知识库可能包含相同内容，搜索结果需注意去重（按标题/来源判断）。

### 步骤1b: 周期相位过滤器（v2.4.3 新增 · 强制）

| Agent9 周期相位 | 筛选约束 |
|-----------------|----------|

| 价格高位僵持（🟡） | 只选业绩兑现确定性高的公司（赚业绩不赚估值），警惕纯估值扩张标的 |

### 步骤2: 建立五维筛选框架（v2.0核心）

**2.1 基本面维度**：

| 指标 | 标准 |
|------|------|
| 营收增速（近2年） | 根据行业特征设定 |
| 利润弹性（经营杠杆） | 收入增长→利润增速弹性 |
| 订单/在手订单 | 有未来收入可见度 |
| 毛利率趋势 | 高于行业均值或持续改善 |
| ROE | > 行业平均 |
| 现金流质量 | 经营现金流/净利润 > 0.7 |

**2.2 产业链维度**：
- 所处环节是否有议价权
- 国产替代空间与进度
- 链主绑定程度
- 利润池迁移中的受益位置

**2.3 技术维度**：
- 技术路线受益程度
- 专利和技术壁垒
- 产品迭代速度
- 客户验证进度

**2.4 估值维度（来自Agent7）**：
- 估值分位：当前处于历史什么位置
- 隐含预期：当前估值隐含的增速是否合理
- 同业比较：与同业/海外对标公司的估值差
- 估值敏感性：不同情景下的合理估值区间

**2.5 交易维度（来自Agent7）**：
- 机构关注度：是否被市场充分关注
- 持仓拥挤度：是否存在筹码拥挤风险
- 过去涨幅：是否已经充分上涨
- 换手率和流动性

### 步骤3: 风险剔除
必须剔除以下类型的公司：
- 财务异常：应收账款/营收>50%、经营现金流持续为负
- 退市风险：*ST、ST、连续亏损、净资产为负
- 重大诉讼或监管处罚
- 公司治理瑕疵：控股股东高比例质押、大规模减持中
- 业绩不可持续：一次性收益占比过大

### 步骤4: 五维预期差分类（v2.0核心新增）

对通过初筛的公司，逐一判定预期差类型：

**4.1 业绩预期差**：
盈利兑现可能高于市场一致预期。
- 标志：自身增速>市场预期增速、经营杠杆效应被低估
- 关键证据：订单数据、产能利用率、客户导入进展

**4.2 格局预期差**：
竞争格局改善但市场尚未反映。
- 标志：CR3提升、新进入者减少、产能出清末期
- 关键证据：市占率变化、竞对退出、进入壁垒提升

**4.3 技术预期差**：
技术路线或产品进度被市场低估。
- 标志：技术进展快于市场认知、产品验证超预期
- 关键证据：专利、量产节点、客户测试反馈

**4.4 估值预期差**：
估值隐含假设过低，存在重估空间。
- 标志：估值分位<25%、隐含增速<合理增速
- 关键证据：估值分位数据、盈利预测对比

**4.5 催化剂预期差**：
短中期存在确定性催化事件，市场尚未充分反映。
- 标志：即将披露的利好事件尚未反映在股价中
- 关键证据：明确的时间节点和事件

### 步骤5b: 垄断型卖铲人专项筛选（v2.4 新增 · 第六类独立筛选）

> **目标**：在五维预期差之外，独立筛选 1-2 家"垄断型卖铲人"——为整个行业提供关键配套、**无论哪条技术路线/哪家终端胜出都需要它**、且环节格局集中、具备定价权的公司。
>
> **线索来源**：Leader 预研固定候选问题"本行业谁是卖铲人？该环节格局是否集中？"（00-leader-agent 1.3）。

**5b.1 七条筛选标准（全部满足方可入选）**：

| # | 筛选标准 | 验证证据 | 数据来自 |
|---|---------|---------|---------|
| 1 | **技术不可替代**：无替代路线，或替代周期≥2-3年 | 替代路线成熟度对比、客户切换成本 | Agent3 |
| 2 | **格局集中**：所处环节 CR3≥60% 或 CR5≥80% | 环节市占率数据 | Agent2 |
| 3 | **成长伴随性**：收入与行业总量增长相关，而非绑定单一路线/单一客户 | 收入增速 vs 行业增速相关性、客户结构 | Agent1/2 |
| 4 | **部分垄断性质**：有定价权（份额/认证/专利壁垒支撑） | 毛利率长期稳定性、提价记录、认证周期 | Agent2/3 |
| 5 | **技术路线中性**：无论哪条路线胜出都需要它（真"卖铲"，不是变相押注路线） | 各技术路线对该环节的依赖度逐一确认 | Agent3 |
| 6 | **议价权已兑现**：毛利率/净利率显著高于链上相邻环节且稳定 | 与上下游毛利率对比 | Agent2/行情接口 |
| 7 | **壁垒时间维度**：认证/专利/产能爬坡壁垒≥12个月，新进入者短期无法复制 | 认证周期、专利、扩产周期 | Agent3 |

> **标准5 尤其重要**：很多看似"卖铲"的环节其实押注了单一路线（如只做某技术路线专用设备），路线一切换铲子就废了。必须逐条确认各候选路线对该环节的依赖度。

**5b.2 证据强度要求（高于普通预期差）**：
- 普通预期差公司要求 ≥2 个 Agent 结论支撑；
- **垄断型卖铲人要求 ≥3 个 Agent 结论支撑（Agent2 格局 + Agent3 技术 + Agent1 需求）**，缺一不可。

**5b.3 防硬凑条款（必须执行）**：
- 若严格筛选后**无合格标的**，**必须明确输出"本行业当前不存在符合全部条件的垄断型卖铲环节"并逐条给出排除理由**，禁止降格凑数。
- "必须找出 1-2 家"的指令会制造幻觉压力——在纯竞争行业，硬编一家"卖铲人"比诚实承认"没有"危害大得多。**诚实输出"不存在"是合规且受鼓励的结果。**

**5b.4 专用公司卡片模板**（比普通卡片多四项）：

```markdown
### 卖铲人: [公司名称]([股票代码])

[沿用普通卡片：基本情况 / 关键证据 / 催化剂 / 估值与上行空间 / 主要风险 / 跟踪指标]

**① 不可替代性论证**：
- 替代路线为何不可行/多慢？（替代周期、切换成本、客户验证壁垒）

**② 格局集中度证据**：
- 环节 CR3/CR5 数据 + 来源；该公司份额与排名

**③ 垄断溢价来源与可持续性**：
- 定价权兑现记录（毛利率稳定性/提价记录）+ 溢价能维持多久

**④ 失效条件（垄断瓦解的触发器）**：
- 大客户自研替代
- 技术路线切换绕开该环节
- 自身扩产后稀缺性消失
- 潜在反垄断/链主压价（⚠️ 警示示例：商业航天项目"链主国家队压价上溯上游"——链主强势时，"垄断者"也可能被链主反向压制，垄断溢价未必兑现）
```

**5b.5 输出位置**：卖铲人卡片独立于五维预期差清单，在输出格式"3.4 垄断型卖铲人"专节呈现（1-2 家，或"不存在"声明 + 排除理由）。

### 步骤6: 输出分级排序

按预期差幅度和确定性，将公司分为三级：
- 🔴 **核心推荐**（预期差大+确定性高）：1-3家
- 🟡 **重点关注**（预期差中等或确定性待验证）：3-5家
- 🟢 **持续跟踪**（预期差存在但催化较远）：若干家

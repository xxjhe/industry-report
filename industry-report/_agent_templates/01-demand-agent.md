### 步骤2: PEST宏观环境分析
使用 WebSearch 联网搜索和分析：

**政治因素（Political）**：
- 行业顶层政策、监管法规、准入要求
- 产业扶持政策（补贴、税收优惠、专项基金、贸易限制）

**经济因素（Economic）**：
- 宏观经济周期：GDP增速、PMI、工业增加值等
- 利率和汇率环境对企业资本开支和居民消费的影响
- 上下游行业景气度传导

**社会因素（Social）**：
- 人口结构和劳动力供给变化
- 消费偏好、环保意识、社会接受度

**技术因素（Technological）**：
- 基础设施成熟度、产业化条件
- 技术普及速度和替代风险

综合结论：宏观环境对行业需求的整体影响判断（有利/中性/不利）。

### 步骤3: 行业生命周期判断（v2.0新增核心）

**3.1 生命周期阶段判断**：
判断行业处于以下哪个阶段：
- 导入期：渗透率<5%，技术尚未成熟，参与者少
- 成长期（加速期）：渗透率5-30%，增速加速，新进入者涌入
- 成熟期：渗透率30-60%，增速放缓，竞争加剧，利润率稳定
- 出清期：渗透率>60%，供给出清，龙头集中度提升

**3.2 判断依据**：

| 判断维度 | 当前状态 | 证据 | 数据来源 |
|----------|----------|------|----------|
| 渗透率 | | | |
| 行业增速（近3年） | | | |
| 竞争者数量变化 | | | |
| 行业利润率趋势 | | | |
| 融资热度 | | | |
| 产能周期位置 | | | |

**3.3 核心变量识别**：
标注当前阶段最重要的核心变量（如渗透率加速点、成本下降拐点、政策催化节点）。

### 步骤4: 渗透率与S曲线分析（v2.0新增核心）

**4.1 当前渗透率测算**：
- 测算当前渗透率（明确分子、分母的统计口径）
- 估算潜在天花板

**4.2 S曲线阶段分析**：

| 渗透率区间 | 阶段特征 | 驱动因素 | 当前行业匹配度 |
|-----------|----------|----------|---------------|
| 0-10% | 早期导入 | 技术验证、政策补贴 | |
| 10-30% | 加速渗透 | 成本下降、产品成熟、渠道扩张 | |
| 30-60% | 快速普及 | 规模效应、网络效应、标准统一 | |
| 60%+ | 饱和阶段 | 替换需求、结构升级 | |

**4.3 渗透率拐点识别**：
识别可能导致渗透率加速/减速的关键拐点：
- 成本拐点：成本下降到经济性临界点
- 性能拐点：产品性能满足主流需求
- 政策拐点：补贴退出或强制推广
- 渠道拐点：销售渠道大规模铺开
- 认知拐点：消费者/客户接受度质变

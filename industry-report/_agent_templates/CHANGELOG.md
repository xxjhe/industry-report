## v2.4.3-r3（2026-10-20）—— 自动化增强 + 门禁静默化

> 驱动：试用户实测反馈——非专业用户环境下，框架因数据源缺失过多询问、暴露内部适配历史，体验不佳。

### 变更
- **门禁静默化**：门禁检查通过后不再向用户输出任何检查过程/结果说明，直接进入研究流程；仅不通过时返回固定话术。落点：SKILL.md、leader-scheduling 阶段-1、datasources §一.0。
- **结构化数据自动择源（不作为门禁项）**：股价/财务/估值数据改为自动阶梯——①环境中已连接的行情 connector（westock-mcp/通达信/Tushare，测通即用）→ ②无则自动 `pip install akshare`（免费、免 token）→ ③新浪/东财公开接口与公告原文补充。**禁止因缺行情数据源向用户提问、汇报或停止**。落点：SKILL.md 硬性纪律3、datasources §1.2/§四（重写）、data-interface DS0、04/05/07/09 各 Agent、source-list-template。
- **自动化运行纪律（小白模式）**：输出目录默认当前工作区不询问；不询问数据源配置、不请求流程确认；仅在"无法自动裁决且直接影响投资结论"的分歧时才询问用户。
- **去除内部适配历史表述**：清理文档中关于知识库来源归属的说明，统一为"自有 IMA 知识库（可选增强，占位符替换）"。
